# 华史时空 · HuaShiShiKong

> 从夏到清，在时间与空间中理解中国历史。

**在线访问：<https://howardli.github.io/HuaShiShiKongSite/>**

面向历史爱好者的中国历史时空软件：拖动时间轴，看四千年间政权兴衰分合、事件发生、人物行迹所至。**每一个事实都带出处，引文保持古籍原文。**

| 规模 | 内容 |
|---|---|
| **206** | 政权与部族实体（夏至清完整谱系，含匈奴、吐蕃、辽、大理等一切并存政权） |
| **691** | 历史事件，其中 158 场带考据行迹线（蒙古西征、郑和下西洋、法显归国、部族迁徙……） |
| **2105** | 人物（历代政权君主 1232 位穷尽收录，年号、庙号、在位齐备） |
| **1085** | 古今地名（今名基准、别名全量检索、建制沿革） |
| **51** | 史料出处（二十四史、《资治通鉴》、《清史稿》、周振鹤《西汉政区地理》等） |

## 三分钟上手

1. **打开站点**——全景时间轴上只有一条正统主线（正史帝系）。
2. **双击任意朝代条带**（比如「唐」）——聚焦六百年窗口：吐蕃、回鹘、南诏、渤海等并存政权随之浮现；再拉近，短命与地方政权尽出。再次双击回全景。
3. **搜索「郑和」**，打开事件卡——七下西洋航线整线入画，站点悬停可看详情，卡片里读《明史》原文引文。
4. **点航线上的任意地名**——地名卡：今名对照、建制沿革、定都于此的政权、发生于此的事件。
5. **✕ 或 Esc 逐级返回**——浏览轨迹是一条可回退的链；拖动时间轴即转向别的年代。

## 使用指南

### 时间轴：一条主线，缩放浮现全景

- 全景（默认）只见**正统主线**——正史帝系一条链到底。这不是「历史上只有这些政权」，而是先给你骨架，细节靠缩放浮现。
- **双击任意朝代条带**：聚焦六百年窗口，并存政权（匈奴、吐蕃、辽、大理……）随之浮现；窗口再拉近到一百五十年以内，短命政权与地方实体尽出；**再次双击回全景**。
- **拖动**光标逐年扫过四千年；**键盘 ← / →** 沿事件年步进——光标自动吸附最近的事件年，每一步都落在「有事情发生」的年份上。
- **平移时间窗**：触控板横刷，或 Shift＋滚轮——纯平移不缩放；页面纵向滚动不受影响。
- 条带之间的**连线就是政权关系**：实线＝承统（继承、改号、分裂、复国），虚线＝征服（灭亡、归附）。拉近后还会浮现**外交桥线**（联姻、册封、战争、会盟——跨泳道的拱形连线），悬停可看关系摘要。
- 地图旁常驻**当年摘要**：光标所在年发生了什么，一目了然，点开直达事件卡。
- 当年摘要里还有**在世人物**：生卒可考且当年在世的人物全列（生年升序），拖到 1076 年能看到王安石、司马光、沈括同榜；点名字直达人物卡。

### 地图：随年份联动

- 图例常驻角落：**●** 事件点　**○** 行迹途经点　**◉** 定位桩。
- **每一个命名点都可点开地名卡**——事件点、行迹途经站、定位桩，无一例外。
- 打开带行迹的事件卡，路线自动上图、镜头整线入画：郑和七下西洋、蒙古西征、法显海路归国、历代部族迁徙……共 158 场。途经点悬停可看站名与详情。
- **◉ 定位桩**是当前选中卡片的位置锚点，悬停有提示。
- **都城层（常驻）**：每个深色白边圆点＝光标当年某个并存政权的在任都城——「谁在场」的空间答案，点击直达政权卡。
- **治所点阵（双模式）**：
  - **单击朝代条带**＝看这个政权——卡片打开＋该政权的治所直接上图（无需聚焦）
  - **双击朝代条带**＝看这个时代——时间轴拉近＋所有并存政权的治所涌现，同城多朝设治处偏移散开、已亡或未生政权的点淡出（**十二朝 1910 点全谱**：秦 42→西汉 103→东汉 105→西晋 172→隋 189→唐 321→北宋 326→辽 99→金 165→元 170→明 178→清 35 府厅州——如「颍川郡·治阳翟」「南京析津府·治析津」「大都路·治大都」；安西北庭都护府亦在图）——悬停看政区名，点击直达地名卡。疆域以「设治之点」表达、不画边界线：边界面是制图者的裁决，点是有出处的。

### 四种卡片与返回链

- **政权 / 事件 / 地名 / 人物**四种卡片共用一个卡槽：从地图点位、搜索、时间轴条带、当年摘要、卡内链接打开的都是它。
- **卡内互链，一路点下去**：政权卡里点都城、点帝王；事件卡里点人物、点地名；人物卡里点他参与的事件。
- **返回链**：每开一张新卡，上一张自动压栈——✕ 或 Esc 逐张返回，悬停关闭钮可预览将回到哪张；返回到底回到当年摘要。
- **浏览器/手机的返回键同样好使**：与 ✕ 一张张回退，返回到底回到当年摘要；前进键则按浏览轨迹重放。
- **政权卡**：兴亡年份（含精度与诸说并列）、都城、世系与年号、承统与征服关系（「a 亡于 b」自然语序）、邦交（和亲 / 册封 / 战争——均锚定具体事件，可跳事件卡）。
- **人物卡**：生卒（有争议并列诸说）、别名、身份；帝王带在位、年号、庙号。**足迹**区逐线点选：点一条只画这一条、镜头随之，再点回全景——多线人物（如朱棣的北征、南征、迁都诸线）不会混成一团。
- **事件卡**：起讫年份、当事人、五段叙事（意义 / 背景 / 经过 / 结果 / 影响）、**古籍原文引文（繁体原样）**；地点区＝事件标记＋途经站，与图上点集一一对应。
- **引文出处可外链**：出处行（如「资治通鉴·卷二一七」）可点，直达维基文库原卷；人物卡与政权卡页脚的 Wikidata 编号同样可点。语料库之外的孤本如实不链。
- **行程回放**：跨多年的路线事件（法显西行、蒙古西征、郑和下西洋……）带「▶ 行程回放」——光标从起始年推进到终年，路线随年逐段浮现（淡显段＝行程未至）；手动拖光标也能看到同样的逐段浮现。
- **地名卡**：今名、别名、建制沿革、定都于此的政权、发生于此的事件。
- **浏览卡片与浏览时间互斥**：拖光标、键盘步进或搜索跳年会收起卡片（返回链一并清空），地图转到那一年——看「此时全景」还是看「这件事」，各不打扰。

### 搜索

- 顶栏一站搜：**政权、人物、事件、地名、年号**，支持**拼音**（如 `zhenghe` 直达郑和下西洋）。
- 政权检索同时吃**自称与史学名**——搜「汉」或「西汉」「前汉」都能到。
- 下拉支持 ↑ / ↓ 键盘导航；年份结果＝跳转到那年。

### 键盘操作（全程可键盘）

| 按键 | 作用 |
|---|---|
| ← / → | 光标沿事件年步进（吸附最近事件年） |
| Tab | 聚焦时间轴 / 分割线 |
| ↑ / ↓ | 时间轴上选中政权条带；分割线上微调宽度 |
| Enter | 打开选中条带的政权卡 |
| Shift＋Enter | 聚焦该时代（与双击等价） |
| Esc | 撤条带选择 → 收卡返回上一张 → 返回到底回当年摘要 |
| ✕（点击） | 与 Esc 同款返回 |

### 布局、分享与离线

- 信息页与时间轴之间的**分割线可拖**（宽度、高度自由调），双击分割线复位，尺寸自动记忆。
- **URL 即快照**：年份与当前卡片都在链接里——复制地址即分享此刻视图，打开别人的链接直接落到同一张卡（分享到社交平台自带预览卡片）。
- **离线可用**：访问过一次后即本地缓存，断网也能完整浏览。
- **可安装**：浏览器「添加到主屏幕／安装应用」后像 App 一样全屏使用（PWA）。

## 数据可信度

- **一切带出处**：以正史为主，引文逐条与古籍原文核对
- **引文保持原文**：一律繁体原样，永不转写
- **争议如实并列**：有分歧的年份与学说（如夏代始年诸说）并列陈列、各注出处，不替读者裁决
- **精度如实标注**：精确到年 / 十年 / 世纪，不确定就标不确定
- **一切政权平等入库**：正统是正史的记载（一个字段），不是收录门槛——匈奴、高句丽、吐蕃、辽与汉唐宋明同等待遇
- **治所点阵口径公开**：每层只主张其断代年（西汉＝元始二年、东汉＝永和五年），治所判定与约位处逐条注记；名录依据＝正史地理志（两汉书语料直提），治所判定引周振鹤《西汉政区地理》等考订
- **不说数据没有的话**：空窗期如实稀疏，不虚构连续性

## 底图

Natural Earth（公有领域）地理底，叠加中国官方口径界线层（国界轮廓、省界、南海诸岛；来源：国家地理信息公共服务平台「天地图」）。历史政权疆域由本项目自身数据表达，底图仅作地理参照。

## English

**HuaShiShiKong** (华史时空, "Chinese history in time & space") is a self-contained web app for exploring Chinese history from the Xia (c. 2070 BC) to the Qing (1912): drag the timeline and watch regimes rise and fall, events unfold, and journeys trace across the map. Every fact carries its source citation from the official histories, with quotes kept verbatim in Classical Chinese; disputed dates are shown side by side rather than adjudicated. Live site: <https://howardli.github.io/HuaShiShiKongSite/>
